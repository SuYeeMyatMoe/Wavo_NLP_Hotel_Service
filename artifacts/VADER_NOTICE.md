# VADER sentiment lexicon

Bundled from the NLTK `vader_lexicon` data package for reproducible offline inference. VADER was developed by C. J. Hutto and Eric Gilbert. See https://github.com/cjhutto/vaderSentiment (MIT license) and https://www.nltk.org/api/nltk.sentiment.vader.html (NLTK implementation, Apache 2.0).

Hutto, C. J. & Gilbert, E. (2014). VADER: A Parsimonious Rule-based Model for Sentiment Analysis of Social Media Text. ICWSM.

This component is a heuristic. It has not been separately evaluated on Wavo's hotel corpus or supported spoken languages.
